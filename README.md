# Meteor Shower Prediction

A data-driven analysis predicting optimal viewing conditions for meteor showers by combining constellation positions, city locations, and moon phase data.

## Data Sources

| File | Description |
|------|-------------|
| `meteorshowers.csv` | Meteor shower event data |
| `cities.csv` | City coordinates and locations |
| `constellations.csv` | Constellation position data |
| `moonphases.csv` | Moon phase calendar |

## Analysis

- **Notebook:** `meteor-showers.ipynb` (57KB)
- **Approach:** Combine astronomical and geographic data to predict best viewing times and locations

## Tech Stack

`Python` · `Pandas` · `NumPy` · `Matplotlib` · `Jupyter Notebook`
